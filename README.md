# Eniac Magist SQL Data Analysis project

## 📊 Project Overview
In this project, we are working for a spain founded online marketplace called Eniac, it is a premier destination for Apple products and curated products. Eniac is planning it's expansion into Brazilian market but as it lacks knowledge of this new market, it plans to utilize Magist, a Brazilian software service company that offers centralized order management system to connect small and medium sized stores with the market. Eniac is considering signing a 3-year contract with Magist as an intermediate step, while it tests the market, creates brand awareness, and explores the option of setting up its own supply chain management.

The two main concerns that we are dealing with are:
1. Eniac’s catalogue is 100% tech products and heavily based on Apple-compatible accessories. It is not clear whether Magist is a good partner for these high-end tech products.
2. Among Eniac’s efforts to have happy customers, fast deliveries are key. The delivery fees resulting from Magist’s deal with the public Post Office might be cheap, but at what cost? Are deliveries fast enough?

## 🛠️ Tools Used
- MySQL
- Python
- Tableau
- Google Colab

## 🔍 Key Learnings
By going through the database we were learning about two main aspects: How magist deals with high end products and it's delivery time. We learned that magist is performing well in both these niche, however it is not showing as much as promise we expected. So we planned to go with magist for a shorter one year trial period, shorted thatn the original plan. This project provided valuable hands-on experience in data analysis, visualization, and interpretation. Through the project, I strengthened my skills in advanced SQL querying, creating interactive Tableau dashboards, and using Python for data manipulation and analysis. Working with Google Colab also enabled efficient collaboration and allowed me to run and manage the analysis in a cloud-based environment.

## 🧩 Challenges Overcame
One of the key challenges was working with limitations in Magist’s dataset, as some valuable information was unavailable, that could have provided additional insights or influenced the analysis. Despite these limitations, we worked with the available data and aimed to extract as many meaningful insights and conclusions as possible. Other challenges included handling large datasets, ensuring data accuracy and consistency, and developing meaningful visualizations. Addressing these challenges strengthened our problem-solving skills and deepened our understanding of data analytics tools and techniques.
